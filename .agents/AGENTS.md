# UI Styling Preferences
- Navigation panels and toolbars should have tight gaps between menu items (e.g. `gap-0` or `gap-1` instead of `gap-2` or larger).
- Arrow/toggle buttons in toolbars or navigation elements should have sharp, square corners (`rounded-none`).
- Icons in navigation toolbars should be appropriately large and visible (e.g., logo icon `size={32}`, tool icons `size={28}`, toggle arrows `size={24}`).
